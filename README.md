# Coral Conundrum 

Analysis of the decline in coral reef fish word frequency around 1998.

## Goal
Explore possible causes: coral bleaching, the internet effect (Google, FishBase), and a public shift in focus from individual fish species to broader ecosystem issues.

## Tools
- Python, pandas, matplotlib, scikit-learn

## Key findings
- 1998 had the highest number of coral bleaching locations, but it wasn’t the only factor.
- The International Year of the Ocean and Google’s launch also played a role.
- A linear model (R² ≈ 0.66) shows a connection with a fish identification book.
- The frequency drop may reflect a shift in public attention toward wider ecological problems.
